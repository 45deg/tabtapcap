# TabTapCap for macOS

アプリの音声やシステム音声を録音し、文字起こしを編集・保存できる Mac アプリです。音声認識は Mac 内で行います。

## 起動

Apple Silicon の Mac と macOS 26 以降が必要です。ソースからのビルドには、macOS 26 以降に対応した Xcode を使います。

```sh
./apps/macos/build.sh
open apps/macos/dist/TabTapCap.app
```

## 録音する

1. 「音声ソース」で録音するアプリか「システム音声」を選びます。ブラウザを選ぶと、そのブラウザで再生中のタブやウィンドウの音声を録音します。
2. 「録音を開始」を押します。初回は macOS の録音許可が必要です。
3. 録音中は音量と途中の文字起こしを確認できます。「録音を停止」すると、録音全体の文字起こしを作ります。
4. 「文字起こし履歴」から録音を選ぶと、音声を再生したり、聞きたい位置へ移動したりできます。

初めて使う言語では、音声認識に必要なデータを macOS がダウンロードする場合があります。

## 編集・書き出し

- 文字起こしの上で「本文のみ」と「タイムスタンプ付き」を切り替えられます。
- 「編集」から直したい発話を選び、本文や段落区切りを修正します。タイトルも変更できます。
- 「編集を保存」または ⌘S で保存します。アプリを開いている間は、履歴を切り替えても編集中の内容は残ります。
- 「書き出し」から TXT・WebVTT・JSON で保存できます。
- 文字起こしがない録音は「文字起こしを作成」、作り直す場合は「その他の操作」（…）の「文字起こしを作り直す」を使います。

再処理・書き出しの前に、編集を保存するか破棄してください。履歴の右クリックからは言語を変えた再処理、発話の右クリックからはコピーやその位置からの再生もできます。

## 設定

- 表示言語と文字起こしの言語を別々に選べます。保存済みの文章は翻訳されません。
- 文字起こしの言語は次の録音から適用されます。録音・文字起こし中は変更できません。
- 句読点や段落の区切り方も調整できます。

## 保存先と注意点

録音と編集結果は、次のフォルダに保存します。

```text
~/Library/Application Support/app.tabtapcap.macos/Recordings/
```

- 録音中にアプリを強制終了したり電源が切れたりすると、音声を復旧できない場合があります。終了前に録音を停止してください。
- 編集の保存に失敗しても下書きは残ります。エラーを確認して再試行してください。
- 以前の SwiftUI 版で保存した WAV も再生・再処理できます。Tauri 版からの履歴移行には対応していません。
